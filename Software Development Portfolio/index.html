Cheat Sheets

HTML Cheat Sheet

  • <!DOCTYPE html>: Defines the document type
  • <html>: Root element
  • <head>: Contains meta-information about the document
  • <title>: Document title
  • <body>: Document body
  • <h1> to <h6>: Header tags
  • <p>: Paragraph
  • <a>: Anchor/link
  • <img>: Image
  • <ul>: Unordered list
  • <ol>: Ordered list
  • <li>: List item

CSS Cheat Sheet

  • color: Sets the color of text
  • background-color: Sets the background color
  • font-size: Sets the font size
  • margin: Sets the margin area
  • padding: Sets the padding area
  • border: Sets the border
  • display: Specifies the display behavior
  • position: Specifies the positioning method
  • flex: Applies flexbox layout
  • grid: Applies grid layout

JavaScript Cheat Sheet

  • let, const, var: Variable declarations
  • function: Defines a function
  • if, else: Conditional statements
  • for, while: Loops
  • document.getElementById: Selects an element by ID
  • document.querySelector: Selects the first element that matches a CSS selector
  • addEventListener: Attaches an event handler
  • innerHTML: Sets or gets the HTML content of an element
  • console.log: Outputs a message to the web console
